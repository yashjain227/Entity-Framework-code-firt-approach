
# 👨‍💼 Employee Management System

A full-stack **Employee Management System** built using **ASP.NET Core MVC**, **C#**, and **PostgreSQL**, implementing complete CRUD functionality using the **Entity Framework Core Code-First approach**.

## 🚀 Features

- **Employee CRUD Operations** – Create, view, update, and delete employee records.
- **Code-First Approach** – Designed database models using C# and generated the PostgreSQL database schema through Entity Framework Core migrations.
- **Server-Side Validation** – Implemented validation to maintain accurate and consistent employee data.
- **MVC Architecture** – Followed the Model-View-Controller pattern for clean application structure.
- **PostgreSQL Integration** – Used PostgreSQL for persistent employee data storage.

## 🛠️ Tech Stack

- **Framework:** ASP.NET Core MVC
- **Language:** C#
- **ORM:** Entity Framework Core
- **Database:** PostgreSQL
- **Approach:** Code-First
- **Architecture:** MVC

## 🎯 Project Objective

The project demonstrates the development of a database-driven **Employee Management System** using ASP.NET Core MVC and Entity Framework Core, focusing on CRUD operations, server-side validation, and database creation and management through the **Code-First approach**.
